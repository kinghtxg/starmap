# StarMap 星图 1.0.0 — 发布说明与上线就绪度评估

> 定版日期：2026-10-21
> 评估口径：以「一个团队接手后能否放心部署到生产内网」为标准，
> 而不是「功能列表是否齐」。**不达标的项如实标注，不粉饰。**

---

## 一、这次定版改了什么

V1.8 之前，产品一直在补识别能力（网段、账实对照、七层转发）。功能是够的，
但有一类问题被长期忽略：**这个程序的资源只进不出**。

被动分析面对的是持续流量。会话表只增不减，且每 2 秒把全表重放给拓扑引擎——
在开发机跑几分钟看不出异常，在真实网络里跑几小时就是内存天花板 + CPU 打满。
**这正是「demo 能用」和「能上线」之间的分界线。**

所以 1.0 不加新识别能力，只做四件事：

| 方向 | 内容 |
|---|---|
| 资源可控 | 会话增量下发 + 三类回收 + 容量硬上限 + 采样窗口封顶 |
| 服务健壮 | HTTP 超时、上报限长、token 常量时间比较、退出去重落库 |
| 配置可信 | 修「后台改完重启就丢」的字段遗漏 |
| 工程底座 | 版本单一来源、CI、覆盖率门禁、七类测试、性能基线 |

## 三、结论

**可以定版。** 作为「单人 + AI 辅助、开源发布、政务内网单点部署」的定位，
1.0 的资源可控性、故障可恢复性、行为可审计性都已到位，且每一项都有测试或实测数据支撑。

**但它不是"大厂全线产品"级别的定版。** 差距集中在三处，且都是**产品定位决定的可接受差距**：

1. **无结构化日志与指标导出** —— 这是真短板，不是定位问题。单人运维时 `log.Printf` 够用，
   一旦要接监控体系就必须补。**列入 1.1 第一优先级。**
2. **无前端自动化测试** —— 拓扑渲染是核心价值，靠人眼回归不可持续。**列入 1.1。**
3. **无 RBAC / 多租户 / 集群** —— 定位使然，不做。接入统一身份后由上游承担授权，
   单点部署不需要集群。

## 四、已知边界（部署前必读）

1. **活跃抓包需要 libpcap 与网卡权限**，且平台相关；
   无权限时请用「PCAP 导入」或「探针上报」两条路，功能等价。
2. **1 万节点级**是当前舒适区上限。超过后建议：
   调大 `aggregate_threshold` 让网段聚合收拢显示，或用下钻视图分区查看。
3. **`Proxies()` 是 O(E) 遍历**。代理节点极多（数千）时该接口会变慢，
   但仍在毫秒级；若未来到十万级边，需要改成增量维护。
4. **会话表打满**的表现是 `Dropped > 0`（见 `/api/stats`）。
   此时应调大 `session_max_count` 或缩短 `session_idle_seconds`。
5. **`session_idle_seconds` 调太小**会把慢速长连接提前回收（表现为拓扑上节点反复上下线）。
   默认 300 秒对政务网办公流量是合适的。
6. **历史 PCAP 导入**按摄入墙钟回收，不受报文时间影响——可以放心导入几天前的抓包。
7. **`staticcheck` 目前只告警不阻断**，待清理完存量告警后转阻断。
   `govulncheck` 已经是阻断项（当前 0 漏洞）。
8. **构建需要 Go 1.26.10+**：这不是随便定的版本下限，而是漏洞扫描倒推出来的——
   低版本 `x/net` 与标准库存在可达漏洞。用旧工具链构建等于把已知漏洞打进发布物。

## 五、验证方式（任何人都能复跑）

```bash
# 1. 全量测试
go test ./...

# 2. 竞态检测（需 gcc / cgo；Windows 无 gcc 时请在 WSL 或 CI 跑）
CGO_ENABLED=1 go test -race ./...

# 3. 覆盖率 + 门禁
go test ./... -coverpkg=./internal/...,./cmd/... -coverprofile=coverage.out
bash scripts/coverage-gate.sh coverage.out 65

# 4. 模糊测试（各 60s）
go test ./internal/parser/ -run '^$' -fuzz=FuzzExtractForwarded -fuzztime=60s
go test ./internal/ledger/ -run '^$' -fuzz=FuzzParseCSV -fuzztime=60s

# 5. 性能基线
go test ./internal/topology/ -bench=. -benchmem -run '^$'

# 6. 端到端 + 进程级冒烟
go run testdata/simprobe.go -server http://127.0.0.1:8080
```

Linux/macOS 可直接 `make ci`（lint + race + cover 一条命令）。
